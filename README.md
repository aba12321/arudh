# عروض — arudh

أداة مفتوحة المصدر للتقطيع العروضي للشعر العربي، مع نماذج من الشعر الجاهلي.
*An open-source Arabic prosody (ʿarūḍ) scansion tool with pre-Islamic poetry samples.*

> **تنبيه مهم:** هذا المشروع مسودة تعليمية. جداول البحور (`arudh/meters.py`) والنسبة التقليدية
> للأبيات (`data/jahili_samples.json`) **لم تُراجَع عروضيًا بعد**. الأداة تعرض «مطابقات محتملة»
> ولا تُصدر حكمًا نهائيًا؛ الحكم لأهل الاختصاص.

## ماذا تفعل؟
1. تحوّل النص المشكول إلى نمط ثنائي (1 = متحرك، 0 = ساكن)، مع معالجة: التنوين، الشدة،
   همزة الوصل، اللام الشمسية، حذف حرف المد قبل همزة الوصل، وتحريك الساكن قبلها.
2. تقابل النمط بجداول التفعيلات (مع الزحافات والعلل) وتعرض كل مطابقة محتملة.
3. تقارن النتيجة بالنسبة التقليدية للبيت في ملف النماذج.

## الاستخدام
```bash
python -m arudh --corpus data/jahili_samples.json
python -m arudh "قِفَا نَبْكِ مِنْ ذِكْرَى حَبِيبٍ وَمَنْزِلِ" "بِسِقْطِ ٱللِّوَى بَيْنَ ٱلدَّخُولِ فَحَوْمَلِ"
```
الإدخال يجب أن يكون **مشكولًا**. اكتب همزة الوصل (ٱ) صراحةً حيث تُكتب ألفًا
(مثل: `بِٱلْعَلْيَاءِ`، `فَٱصْبَحِينَا`) لأن الألف وحدها قد تلتبس بألف المد.

## نقاط خلافية تُركت مفتوحة
- **إشباع حركة آخر الصدر والعجز:** تجرّب الأداة الحالتين (بإشباع وبدونه) وتذكر أيهما طابق.
- **الصور المسموحة لكل تفعيلة (خاصة العروض والضرب):** جداول أولية قابلة للتعديل.
- **تشكيل النماذج:** مكتوب يدويًا ويحتاج تدقيقًا.
- **أبيات لا تطابق:** تُعرض كـ«للمراجعة» ولا تُعدَّل الجداول لإجبارها على المطابقة.

## المساهمة
- راجع تشكيل النماذج وصحّح نسبتها، ثم اجعل `verified: true`.
- أضف بحورًا (تبقّت معظم البحور الستة عشر) في `arudh/meters.py`.
- أضف نماذج جديدة في `data/`.
- شغّل الاختبارات: `python -m pytest tests`
